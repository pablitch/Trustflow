thermostat
O limite crítico (LSC) é a temperatura máxima tolerada. Acima dela, a cadeia do frio é considerada rompida. O custo unitário alimenta o cálculo de valor protegido.
factory
Fornecedores são as origens das cargas — os pontos onde o sensor é acoplado e a custódia monitorada começa.
local_shipping
Transportadoras executam o transporte. O desempenho de cada uma é auditado e pode render o selo TrustFlow Verified.
store
Clientes são os destinos — as docas onde a carga é recebida, o veredito é consultado e o sensor devolvido.
nfc
Cada sensor físico é rastreado por ciclos de uso (meta de amortização: 45), bateria e data de calibração RBC.
